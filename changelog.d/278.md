### Added

- `box cp [--user U] SRC DST` copies a file or directory between the host and a box, scp-style (one side `<box>:<path>`), over `incus file push/pull` with no SSH; it works on the restricted tier and for shared tenants via `--as` (#278).
- `box cp` follows the entry model: root by default (remote paths against `/root`, files `root:root`); `--user U` resolves against U's passwd home in the box, owns pushed files as U, and refuses a missing U before copying (#278).
