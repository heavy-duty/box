## Why a round is needed

This is the tenancy window (#279–#285, #287) and all of epic #253 (#288–#292).
It changes the seed (no default user, no tmux, no toolchain, no swap), the entry
model (root by default, `--user` opt-in), shared tenants and service grants,
firewall drop-ins, and the ACL shape (#298). An existing host needs
`box setup-host` to converge the ACL.

## Round — 2026-11-23 — RED, 79/89

The round ran against the published `0.11.0-rc1` tag (`df6b6c9`) on a drill host built with heavy-duty/infra's drill-host script (a nested Incus VM, 11 GiB, so boxes were minted at 3 GiB/2 CPU). Run ID `drill-0.11.0-rc1-20261123-01`.

| Phase | Result |
| --- | --- |
| I install | 1/1 |
| A Incus semantics | 8/8 |
| B the box surface | 47/47 |
| G guest interiors | 6/16 |
| C isolation baseline | 9/9 |
| E box expose | 7/7 |
| D the contract, stated | 0/0 |
| T teardown | 1/1 |

**The isolation audit is clean:** egress and public DNS pass; box→host, box→RFC1918, sibling traffic, DNS enumeration and host→box are all dropped; IPv6 is off.

**The drop-in probe passed**, which confirms #298 (the ACL drop is now written around the gateway) on real hardware.

**Failed (10), all in G, all one cause (#300):** chrony was read before it had synced, then the ±3h skew probe stepped the guest clock through the agent. That dropped the agent connection until `box restart`. Every later G probe could not reach the guest: chrony tracking, both skews, passwd, `box root`, `checkup` seed and `/tmp`, ENOSPC, swapon and the converger probe. #297's agent-wait guard did not fire, so the box was up when G began. This is a harness defect, not a box one. It is fixed for rc2 by #300, and rc2 also adds `box cp` (#278) with three real-host probes (92 in total).

**Verdict:** RED. rc2 follows.
