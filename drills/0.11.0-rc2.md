## What changed since rc1

- **#300:** phase G's clock probes run last, inside the guest, against its monotonic clock. chrony is polled until it has a source. A restart follows, so phase C starts healthy.
- **#278:** `box cp`, scp-style, over `incus file`. It defaults to root, and `--user` is opt-in. `-` is stdin/stdout. Shared-tenant members use the plain grammar: their half runs before sudo, as the member, and the tenant only sees a tar stream. Pulled streams are safety-checked.
- **Drill:** phase G grows from 16 to 19 probes (a box cp root round trip, a recursive directory, `--user` ownership of the file and its new parents). That makes **92** in total.
- CI's real-Incus rehearsal measured a member's `box --as … cp` directory round trip on #301 (118/118).

**The isolation audit is clean** (egress and DNS pass; box→host, RFC1918, sibling, DNS enumeration and host→box are all dropped; IPv6 is off). **#300 held:** the agent survived the clock probes, chrony tracking passed, and every other interior probe measured the guest. **Failed (3), all in G (#303):**
- `box cp` of a directory onto a missing path with a different name was refused. The admin path required the name to match; scp doesn't. This is a product fix: a true scp rename.
- Both ±3h skew trials timed out at 120s, now measured honestly with the agent alive. chrony steps only after polling its sources again (minpoll 64s, several samples). The window becomes 300s, and a timeout now records chrony's own view.
